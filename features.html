Type: Source-to-Source Programming Language Compiler (Transpiler)

Target Platform: JavaScript (Node.js Runtime)

GitHub Repository: https://github.com/Ayushkumar055/AyuCompiler

1. Executive Summary

AyuCompiler is a custom domain-specific language (DSL) compiler developed in JavaScript. It parses custom .ayu source files, generates an Abstract Syntax Tree (AST) using recursive-descent parsing, and transpiles the validated AST into clean, standard ES6 JavaScript.

2. Architecture Pipeline

  .ayu Source Code ──▶ [ Lexer ] ──▶ Tokens ──▶ [ Parser ] ──▶ AST ──▶ [ CodeGenerator ] ──▶ .js Output ──▶ Node.js

4. Built-in Function Reference

  • length(collection): Returns array element count or string length.
  • contains(collection, value): Returns boolean true if element exists.
  • indexOf(collection, value): Returns 0-based index or -1 if not found.
  • push(array, value): Appends value to the end of the array.
  • pop(array): Removes and returns the last element.
  • upper(string) / lower(string): Converts text case.
  • input(prompt) / inputNumber(prompt): Reads string or numeric input synchronously.
