AyuCompiler is a JavaScript engine written in JavaScript. Write real .js code — variables, functions, closures, loops, arrays — and a hand-built lexer, recursive-descent parser and tree-walking evaluator run it directly. No eval, no Function(), no shortcuts.

01

          
Lexer

          
Scans raw JavaScript text into a token stream — keywords, identifiers, numbers, strings, template literals — tracking line/column for every one.

        

        

          
02

          
Parser

          
A recursive-descent parser builds an Abstract Syntax Tree, resolving operator precedence, arrow functions, and assignment targets.

        

        

          
03

          
AST

          
The tree is walked to validate structure — scoping, const-reassignment, and reference errors are caught before evaluation.

        

        

          
04

          
Evaluator

          
Executes the AST directly with real lexical scoping and closures — no code generation, no eval.

        

      

    

  


  

    

      

        
What it can run

        
A meaningful subset of real JavaScript — enough to write recursive functions, closures, and array pipelines.

      

      

    

  


  

    

      

        
Supported globals & methods

        
Values in AyuCompiler are real JavaScript values under the hood, so native array/string/Math methods work out of the box.
