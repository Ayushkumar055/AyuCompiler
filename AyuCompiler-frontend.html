A small language,
compiled to JavaScript.

AyuCompiler is a custom domain-specific language. Write .ayu source, and a hand-built lexer, recursive-descent parser and code generator turn it into clean, runnable ES6 — no dependencies, no VM.

Try it in the playground View source
hello.ayu hello.js 

        
compiles to →

      

    

  


  

    

      

        

          
01

          
Lexer

          
Scans raw .ayu text into a flat stream of tokens, tracking line and column for every one.

        

        

          
02

          
Parser

          
A recursive-descent parser turns the token stream into an Abstract Syntax Tree, enforcing grammar and operator precedence.

        

        

          
03

          
AST

          
The validated tree is walked once to check structure before anything is emitted.

        

        

          
04

          
Code Generator

          
Emits readable ES6 — same control flow, same names — ready for the Node.js runtime.

        

      

    

  


  

    

      

        
What the language supports

        
Everything a small imperative language needs: variables, control flow, functions and arrays, with real syntax errors instead of silent failures.
